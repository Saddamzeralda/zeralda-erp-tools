# Tools & Utilities — Zeralda ERP

يحتوي هذا المجلد على أدوات الإدارة، حماية الملكية الفكرية، فحص الشبكة، وأدوات المطور المنفصلة.

## تصنيف الأدوات (Tool Categories)

### 1. أدوات إدارة النظام والتراخيص (System & License Management)
- **`protection_toolkit.py`**: واجهة الإدارة والتحكم الشاملة لجميع خصائص الحماية (التراخيص، التمويه، الإحصائيات، فحص النزاهة). يمكن تشغيلها عبر `START_TOOLKIT.cmd`.
- **`keygen_tool.py`**: واجهة رسومية (Tkinter GUI) متكاملة لتوليد رموز التفعيل وإدارتها وتصديرها.
- **`inject_license.py`**: سكربت لحقن ترخيص يدوي في قاعدة البيانات للأجهزة المحلية غير المتصلة بالإنترنت.
- **`reset_admin_password.py`**: سكربت موحد لإعادة تعيين كلمة مرور المسؤول (Admin) تلقائياً لأي بريد إلكتروني مسجل كمدير في `data/users.json`.

### 2. أدوات التمويه وفحص النزاهة (Obfuscation & DRM)
- **`obfuscate_py.py`**: أداة تشويش وتشفير كود بايثون الحساس (باستخدام marshal و base64) مع دعم خيار الاستعادة `--restore`.
- **`obfuscate_js.py`**: أداة تشويش مكتبات الجافاسكربت الأمنية (`license_*.js`) مع دعم خيار الاستعادة `--restore`.
- **`_py_originals/` & `_js_originals/`**: مجلدات مخصصة لحفظ النسخ الأصلية غير المشوشة قبل تطبيق التمويه.

### 3. أدوات الشبكة والاستضافة (Networking & Host Tools)
- **`network_host_manager.py`**: إدارة أسماء المضيفين المحلية وتسهيل وصول الأجهزة في الشبكة المحلية LAN.
- **`mdns_server.py`**: خادم إعلان محلي متعدد البث (mDNS) لتمكين اكتشاف الخادم على الشبكة بدون الحاجة لـ IP ثابت.
- **`SETUP_HOSTNAME.cmd`**: ملف أوامر سريع لإعداد وحجز النطاق المحلي.

### 4. خدمات إضافية ومحركات خارجية
- **`tesseract/`**: النسخة المحمولة المدمجة لمحرك التعرف الضوئي على النصوص (OCR).
- **`generate_proforma_invoice_pdf.py`**: سكربت مساند لتوليد قوالب فواتير شكلية بصيغة PDF.
- **`python-embed/`**: بيئة بايثون المدمجة المستقلة المستخدمة في تثبيت ويندوز.
