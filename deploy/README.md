# Deployment Configurations — Zeralda ERP

يحتوي هذا المجلد على ملفات تكوين منصات الاستضافة السحابية المختلفة:

- **`railway.json`**: إعدادات بناء وتشغيل الحاوية السحابية على منصة Railway.
- **`render.yaml`**: إعدادات الاستضافة لخدمة Render Web Service.
- **`nixpacks.toml`**: إعدادات حزم وبيئة البناء التلقائي لـ Nixpacks.
- **`Procfile`**: أمر تشغيل خادم الويب لمنصات PaaS المتوافقة مع Heroku/Procfile.
