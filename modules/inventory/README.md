# 🏢 Zeralda ERP - وحدة المخزون
**نظام إدارة المخزون الذكي مع المزامنة السحابية**

---

## 📋 نظرة عامة

وحدة المخزون في Zeralda ERP هي نظام إدارة مستودع متكامل يسمح لك بـ:

✅ إدارة الآلاف من المنتجات  
✅ تتبع حركات المخزون (الإضافة والسحب)  
✅ عرض تقارير وإحصائيات فورية  
✅ المزامنة التلقائية يومية مع Google  
✅ دعم عدة شركات وفروع  
✅ نسخ احتياطية آمنة وتدقيق شامل  

---

## 🚀 البدء السريع

### الخطوة 1: افتح الملف
```bash
modules/inventory/inventory_management.html
```

### الخطوة 2: أضف منتجات (أو استأنف العمل)
- اضغط زر "إضافة منتج"
- ملأ البيانات المطلوبة
- احفظ

### الخطوة 3: فعّل المزامنة
شغّل في console المتصفح:
```javascript
setupGoogleSync('your-email@gmail.com');
setupAutoSync();
```

### الخطوة 4: استمتع!
المزامنة تحدث تلقائياً كل يوم ✅

## 🐛 استكشاف الأخطاء الشائعة

### المشكلة: لا يمكن إضافة منتج
**الحل:**
1. تأكد من تفعيل JavaScript
2. امسح localStorage (Settings → Reset)
3. أعد تحميل الصفحة

### المشكلة: الأسهم غير صحيحة
**الحل:**
1. قم بفحص دوري
2. راجع سجل الحركات
3. استخدم `checkAndFixConsistency()`

### المشكلة: المزامنة لا تعمل
**الحل:**
1. افتح SYNC_DIAGNOSTICS.md
2. شغّل أدوات التشخيص
3. تابع التعليمات
